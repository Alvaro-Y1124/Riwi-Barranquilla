# Age Verification System

A simple web application that checks if a person is old enough (18 years or older).

## What it does

This app asks for your name and age. Then it tells you if you are young or old enough to be an adult.

## How to use

1. Open the `index.html` file in your web browser
2. Write your name in the first box
3. Write your age in the second box
4. Click the "Check" button
5. Read the message that appears

## What happens

- If you don't write your name: You get a message asking for your name
- If you don't write your age: You get a message asking for your age
- If you write a negative number: You get an error message
- If you are under 18: You get a message saying you are young
- If you are 18 or older: You get a message saying you are an adult

## Files in this project

- `index.html` - The main web page
- `main.js` - The code that makes everything work
- `style.css` - The code that makes everything look nice

## How to run

1. Download all files
2. Put them in the same folder
3. Double-click on `index.html`
4. Your web browser will open the app

## Browser support

This app works on all modern web browsers like Chrome, Firefox, Safari, and Edge.
