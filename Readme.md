Project Overview
This is a responsive personal portfolio website that showcases my skills, work and track record as a Full Stack developer. The page features a contemporary design with smooth transitions and adjusts to any screen size.

Features
Responsive design: comprehensive design adapted for desktops, tablets and mobiles.
Interactive components: hover effects, smooth scrolling, and transition animations.
Presentation of the work: exhibition of 3 selected projects along with the technologies used.
Contact form: operational contact area with form verification.
Dark theme: attractive mix of dark tones with highlight colors.

Technologies used
Interface:

    HTML5 (Semantic Structure)

CSS3 (Custom Properties, Flexbox, Grid)Tools:

    Google Fonts (Space Grotesk)

Font Awesome IconsCSS Variables for theming
